# 设计进行时

中文 UI 设计师求职作品集。源内容集中在 `app/content.json`，首页、项目详情与简历共用内容。

## 更新内容

打开网站页脚的“编辑内容草稿”，可以修改个人信息、项目文案、封面、章节说明与图片，调整项目顺序和可见性。

草稿仅保存在当前浏览器，**不会自动同步其他设备或发布**。图片可用 HTTPS 链接，或上传每张不超过 2 MB 的 PNG、JPG、WebP、GIF。浏览器容量有限，大量素材建议保留原文件并交给制作方整理。导出的 JSON 包含上传的图片数据，换设备前先导出备份。

更新正式网站：导出 `portfolio-content.json` 并发回制作对话，或将其内容替换 `app/content.json` 后重新构建并发布。真实图片可以放到 `public/images/`，内容中引用 `/images/文件名.webp`。编辑页支持现有五个项目；新增独立项目可由制作方加入内容文件，动态详情页按相同结构展示。

`previewMode: true` 显示空图片区域和编辑入口。准备对招聘方公开前关闭此模式，并补齐姓名、联系信息、简历和作品；没有图片的项目与空章节会隐藏。`visible: false` 隐藏首页项目卡片。当前网站先保持私人访问。

项目文字只使用已确认经历。浙江移动整体风格、首页与个人中心由他人牵头；江苏掌厅个人中心及部分首页楼层由本人参与设计。未填写的成果、数据和图片不会被编造。

## 本地运行

使用 Node.js 22.13 或更高版本。首次运行 `npm install`，随后 `npm run dev`。生产构建为 `npm run build`。本项目使用 Sites / Vinext，部署信息保留在 `.openai/hosting.json`。

草稿导入后若浏览器容量不足，应先导出，再减少大图片。浏览器数据清除会丢失未导出的本机草稿。
